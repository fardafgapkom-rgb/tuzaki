# TUZAKI — Render'ga joylash

1. Papkani GitHub'ga yuklang (yangi repo).
2. render.com → New → **Web Service** → shu repo'ni tanlang.
3. Sozlamalar:
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
4. (Ixtiyoriy) Environment → `OWNER_PASSWORD` = istalgan parol. Qo'ysangiz, Ctrl+Shift+J bosganda parol so'raladi.
5. Deploy. Tayyor!

## Ishlatish
- Kirish — live'ga kirish (faqat 1 kishi, boshqalarga "Joyband!").
- Ctrl+Shift+J — ega bo'lish / egalikdan chiqish (bitta ega).
- Ega **D** tugmasini bosib turib gapiradi, qo'yib yuborsa ovoz to'xtaydi. Ovozni live ichidagi odam eshitadi.
- Telefonda: "🎤 Gapirish" tugmasini bosib turing.
- Mikrofon uchun sayt HTTPS bo'lishi kerak (Render o'zi beradi).
